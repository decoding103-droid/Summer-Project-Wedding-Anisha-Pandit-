# Website Preview

## Home Page

Welcome to the **Wedding Venue Management System**, a modern web application developed by **Anisha Pandit**. The platform is designed to simplify wedding venue booking and reservation management through an intuitive and user-friendly interface. It allows administrators to manage venues, customers, bookings, and reports efficiently while providing a seamless browsing experience.

### Available Wedding Venues

This page displays a collection of available wedding venues along with essential details such as venue name, location, seating capacity, contact information, pricing, and current availability. Administrators can also perform actions such as booking, editing, or deleting venue records directly from this interface.

The secure Admin Login page authenticates administrators before granting access to the management dashboard. Only authorized users can access administrative features such as venue management, customer records, bookings, reports, and system data.

### S Admin Dashboard

The Admin Dashboard provides a centralized overview of the system. It displays key statistics including total customers, bookings, available and reserved venues, revenue collected, and a history of recent bookings. This dashboard enables administrators to monitor system activity and manage records efficiently from a single interface.
